# Product Context

## Why this exists
K12 MyPortal has multiple portals, APIs, and Azure infrastructure. This repo centralizes architecture and delivery knowledge so teams can:
- Onboard quickly
- Make consistent engineering decisions
- Operate and deploy reliably

## Users
- Engineers (frontend, backend, platform)
- Architects and delivery leads
- Operations/SRE

## Documentation Principles
- Prefer concrete sources (ADRs, diagrams, pipeline/IaC configs) over assumptions.
- When sources are missing, record the gap and link to where the source should live.
