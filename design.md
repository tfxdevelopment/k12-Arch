# Design - Spec-Driven Workflow Demo

## Architecture

The demo consists of a single markdown file located at `docs/workflow-demo.md`.

## Content Strategy

- Introduction to Spec-Driven Development.
- Visual representation of the 6-phase loop (Analyze, Design, Implement, Validate, Reflect, Handoff).
- Practical "Quick Start" guide.

## Data Flow

User Request -> Spec-Driven Workflow -> requirements.md -> design.md -> tasks.md -> Implementation -> Verification -> Handoff.
