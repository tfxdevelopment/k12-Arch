# K12 Architecture Documentation Site

Nuxt Content-powered documentation site for K12 MyPortal Enterprise Architecture.

## Quick Start

```bash
# Install dependencies
npm install

# Start development server (http://localhost:3000)
npm run dev

# Build for production
npm run generate
```

## Features

- ✅ Markdown-based documentation
- ✅ Syntax highlighting (C#, TypeScript, SQL, etc.)
- ✅ Dark mode
- ✅ Table of contents
- ✅ Responsive design
- ✅ Full-text search
